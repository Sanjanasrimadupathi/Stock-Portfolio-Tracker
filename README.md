# 📈 Stock Portfolio Tracker

## 📌 Description

A simple Python-based application that helps users track their stock investments and calculate the total value of their portfolio. It demonstrates basic programming concepts such as user input, calculations, lists, and conditional statements.

## ✨ Features

* Add stock details
* Track stock quantities
* Calculate investment value
* Display portfolio information
* Simple and easy-to-use interface

## 🛠️ Technologies Used

* Python 3
* Jupyter Notebook / Google Colab

## 🎯 Objective

The main objective of this project is to develop a simple tool for managing stock portfolio information while practicing basic Python programming concepts.

## ▶️ How to Run

1. Open the Python file or Jupyter Notebook.
2. Run the program.
3. Enter the required stock details.
4. View the calculated portfolio value.
